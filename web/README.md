# Artgram — Frontend (React + TypeScript + React Router)

```
npm install
npm run dev
```
Ouvrir l'adresse affichée (http://localhost:5173).

- `src/data.ts` : toutes les données fictives. Pour utiliser vos vrais dessins, mettez vos images dans `public/images/` et renseignez `src: '/images/mon-dessin.png'` sur chaque publication, tutoriel, commande ou artiste.
- `src/pages/` : une page par fichier. `src/App.tsx` : routes.
- `src/styles.css` : couleurs (variables `--bg`, `--violet`…) et styles.
